Perbaikan Mode Offline, Kelola Channel, dan Info Pasar:
- Chip sesi offline di Beranda kini bisa diketuk → langsung membuka layar Mode Offline
- Kebijakan privasi kini tampil di aplikasi (WebView) dengan persetujuan sekali — centangan aktif sesudah gulir sampai bawah
- Kartu channel kini mengikuti satuan tampilan dan menampilkan waktu dibuat ("Dibuka")
- Mode Offline kini tersedia tanpa gerbang testnet
- Kartu channel LSP kini menampilkan id node
- Kurs NUX/IDR di Info Pasar kini diambil langsung dari CoinPaprika dalam satu panggilan
